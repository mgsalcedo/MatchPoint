# ADR-0001 — PWA first

## Status

Accepted

## Context

MatchPoint needs to validate product demand quickly across mobile users in Lima and Callao. Building native iOS and Android apps would increase cost, complexity, and iteration time.

## Decision

MatchPoint PMV will be built as a Progressive Web App.

## Rationale

Faster to build; easier to share via link; works on iOS and Android browsers; can be installed to home screen; lower development cost; easier iteration during validation.

## Consequences

Native app features are deferred; PWA performance must be optimized; mobile-first design is mandatory (BR-022, BR-023).
