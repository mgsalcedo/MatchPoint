# ADR-0002 — Sport Match™ as core experience

## Status

Accepted

## Context

MatchPoint could start as a directory, search engine, map, or calendar. However, the product differentiation is matching users with the right community.

## Decision

Sport Match™ will be the first and primary experience.

## Rationale

Makes the product feel personalized; avoids overwhelming users with lists; creates differentiation from Google Maps and Instagram; generates structured user intent data; supports the North Star (contact generation).

## Consequences

Search and map are secondary; manual browsing can come later (V1.2, per `docs/roadmap.md`); matching logic becomes a core product asset (see `docs/matching-engine.md`).
