# ADR-0008 — Luma-inspired design without copying

## Status

Accepted

## Context

The desired visual direction is inspired by Luma's clean, curated, event-like experience.

## Decision

MatchPoint may use Luma as a quality benchmark but must create its own original visual identity (see `docs/visual-direction.md`).

## Rationale

Luma-like curation fits community/event discovery; MatchPoint needs premium, clean, mobile-first design; copying proprietary UI would be inappropriate and strategically weak.

## Consequences

Do not copy exact layouts, colors, icons, assets, copy, or branding (`docs/visual-direction.md`'s anti-copy rule); translate inspiration into sports discovery language; use original components and design tokens (`docs/design-system.md`).
